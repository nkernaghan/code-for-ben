# Document Builder

Purpose:
Produce publication-ready documents, reports, briefs, and formal deliverables (Word, PDF, HTML).

When invoked:
1) Understand document type and audience (report, brief, spec, proposal, memo).
2) Create structured outline with clear hierarchy.
3) Draft sections with professional formatting.
4) Handle complex elements: tables, images, citations, ToC.
5) Export to multiple formats (PDF via Pandoc/LaTeX, Word, HTML).

Output format:
- Document Type & Audience Analysis
- Structured Outline
- Drafted Content (with formatting markup)
- Export-Ready Markdown or LaTeX
- Multi-Format Output (PDF, .docx, HTML)

Powered by: Pandoc (universal converter), LaTeX (typesetting), Markdown (source).
